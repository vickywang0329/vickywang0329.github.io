Privacy Policy

Job Application Assistant · Last updated: 10 October 2026

Job Application Assistant is a personal automation tool operated by I-Hsiao Wang for her own job search. It is used only by its owner and is not available to the public.

What data is accessed

With the owner's explicit Google authorisation, the tool reads emails in the owner's own Gmail account that carry the label "job-alerts" (job-alert emails from job boards such as LinkedIn, SEEK and Indeed). It reads the subject, sender and body of these emails, and adds a "job-processed" label to emails it has handled. It does not read, send or delete any other email.

How the data is used

The tool extracts job postings (job title, company, location, link and short description) from these emails so the owner can review and track job opportunities. Email content is sent to the Anthropic Claude API solely to extract and assess job postings.

Storage and sharing

Extracted job information is stored in a private database (Supabase) accessible only to the owner. No data is sold, shared with third parties for advertising, or used for any purpose other than the owner's own job search.

Google API Services User Data Policy

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from the Google Account third-party access page.
